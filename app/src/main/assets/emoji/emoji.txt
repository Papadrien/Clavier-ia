# Catalogue des emojis du clavier (story 1.15).
# Format : une ligne « @id » ouvre une catégorie, puis les emojis, séparés par des espaces (sur une
# ou plusieurs lignes). Les lignes commençant par # sont ignorées. L'ordre est celui d'affichage.
# Contenu : emojis simples et séquences courantes (ZWJ, drapeaux, touches), sans variantes de teinte
# de peau (non prévues par la story). Ordre des catégories/sous-groupes inspiré de la liste CLDR/Unicode
# (approximation faite à la main), drapeaux de pays classés par code ISO. Chaque entrée a été
# vérifiée comme rendue par Noto Color Emoji (Unicode 15.x). L'appareil filtre au runtime ce que
# sa propre police sait afficher (Paint.hasGlyph), donc les emojis trop récents pour la version
# d'Android sont simplement masqués.
